# Portfolio de tests manuels QA

Ce répertoire contient des exemples d'artefacts de tests manuels que j'ai réalisés pour démontrer mes compétences en assurance qualité fonctionnelle. Il inclut un plan de test, des cas de test, des rapports de bogues et une matrice de traçabilité. Les documents sont inspirés d'applications web et API afin de refléter des scénarios réels rencontrés dans des projets logiciels.

* `test-plan.md` : décrit la portée, la stratégie et les critères d'acceptation pour une application de réservation.
* `test-cases.md` : liste détaillée de cas de test fonctionnels, de régression et exploratoires.
* `bug-reports.md` : exemples de rapports d'anomalies avec description, étapes de reproduction, sévérité et priorité.

Ces artefacts peuvent servir de référence lors de mes candidatures pour des postes d'analyste QA, afin de montrer ma capacité à structurer et documenter un effort de test manuel.
