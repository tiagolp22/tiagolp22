# Plan de test – Application de réservation

## Objectif
Définir la portée et la stratégie de test pour l'application de réservation en ligne afin d'assurer la qualité des fonctionnalités principales avant la mise en production.

## Portée
- Flux de réservation (création, modification, annulation)
- Authentification et rôles utilisateurs
- Validation des règles métiers et contraintes de date
- Tests de régression sur les fonctionnalités existantes

## Stratégie
- Tests fonctionnels manuels basés sur les exigences utilisateur
- Tests exploratoires pour découvrir des scénarios inattendus
- Tests de régression exécutés à chaque itération
- Utilisation de données de test variées et de valeurs limites

## Critères d'entrée
- Les stories d'utilisateur sont complètes et acceptées par l'équipe
- L'environnement de test est stable et prêt
- Les données de test sont disponibles

## Critères de sortie
- Tous les cas de test critiques sont réussis
- Les anomalies bloquantes et majeures sont corrigées et re-testées
- Un rapport de test est produit et approuvé
